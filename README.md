🌿 HealthPal – Integrated Health Support Platform

HealthPal is a full-stack healthcare support system built to provide accessible medical services, donation-based medical sponsorship, mental health counseling, and NGO-driven medical missions — all within a single unified platform.

Designed for communities with limited healthcare access, HealthPal connects patients, doctors, donors, NGOs, and counselors through a set of powerful, secure, and scalable APIs.

API documentaion on postman: https://documenter.getpostman.com/view/49387501/2sB3dSRUr3  
🚀 Key Features
🩺 1. Remote Medical Consultations

Book appointments with verified doctors

Doctor & patient dashboards

Real-time messaging during consultations

Audio/video consultation call logging

Specialty filtering to help patients find the right doctor

💚 2. Medical Sponsorship System

Patients can open medical cases

Donors can support cases with money, medicine, or supplies

NGOs can verify and support cases

Donation tracking, receipts, and transaction history

🧠 3. Mental Health Counseling

Private counseling sessions

Anonymous therapy chat

Support groups with moderated discussions

Messaging system between patient and counselor

🏥 4. NGO Missions & Community Support

NGOs can create medical missions

Doctors can join missions

Patients can request help

Community health alerts and announcements

🧪 5. Medical Inventory & Equipment

Track medicines, supplies, and equipment

Manage stock status, requester info, and delivery updates

📚 6. Health Guides & Alerts

Multilingual health articles

Important community health alerts

Online & onsite workshops

🗄 Database

The system includes a comprehensive MySQL schema covering:

Users, patients, doctors, NGOs

Appointments, consultations, sessions

Donations, cases, inventory, missions

Guides, alerts, and workshops

All relationships include proper foreign keys, cascade rules, and role-based interactions.
